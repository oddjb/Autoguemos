autoguemos (conjuguemos helper)

1. unzip this archive and open chrome://extensions.
2. enable developer mode, disable the previous helper, and use load unpacked to select the conjuguemos-helper folder.
3. open your conjuguemos assignments page. click autoguemos on the assignment card to load its question pool without leaving the page.
4. set attempts, correct count, and minutes. select questions and prepare a preview. submit preview sends simulated records immediately using your signed-in browser session. reported time is not a delay; the result is subject to server validation.
5. on an open assignment, use choose assignment to load that activity and complete it with your parameters.

runs locally on your browser, data is never sent anywhere. (unlike some other extensions..)
if something breaks then goodluck.. you got this.
