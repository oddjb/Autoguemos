autoguemos (conjuguemos helper)

1. unzip this archive and open chrome://extensions.
2. enable developer mode, disable the previous helper, and use load unpacked to select the conjuguemos-helper folder.
3. open your conjuguemos assignments page. click autoguemos on the assignment card to load its question pool without leaving the page.
4. set attempts, correct count, and minutes. select questions and prepare a preview. submit preview sends simulated records immediately using your signed-in browser session. reported time is not a delay; the result is subject to server validation.
5. on an open assignment, use choose assignment to load that activity. use manual in the header to switch to answer, list, and timed run; auto returns to the assignment view.

conjugation and vocabulary assignments are supported when their activity data matches the formats inspected. the question selection uses page data; generated attempts are not records of activity actually performed. no account cookies are sent to autoguemos servers. check the server response and gradebook to verify a result.

settings: submit alert is enabled by default. before sending, it checks the latest dated gradebook result against the proposed start time. overlap or an unavailable gradebook requires checking the acknowledgement box and selecting yes, submit. this check applies to the assignment submission preview.

assignment cards are highlighted while hovered or keyboard-focused. a confirmed saved response opens a success dialog; an already-saved or unrecognized response is identified separately. drag the panel header toward the left edge to tuck it into a side tab; click the tab to reopen. the x closes the helper and removes its buttons and highlights until the page reloads.
